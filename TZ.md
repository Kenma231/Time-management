1.2. Назначение и цели создания системы:

1.2.1. Назначение системы: 

Система предназначена для учета рабочего времени, планирования задач и анализа эффективности их выполнения.

1.2.2.Цели создания системы: 

- Избавить пользователей от необходимости использования разных инструментов для 
планирования и учета времени, обеспечив единое пространство для управления задачами и временными затратами.

- Предоставить руководству инструмент для анализа эффективности использования рабочего времени сотрудниками.

1.3.  Описание объекта автоматизации

Процесс учета рабочего времени и управления задачами включает в себя создание, распределение и отслеживание 
выполнения задач, фиксацию временных затрат по каждой задаче, формирование отчетных данных о продуктивности.

1.4.  Требования к системе 

1.4.1. Требования к системе в целом:

1.4.1.1.Требования по эргономике и технической эстетике: 

Интерфейс системы должен быть интуитивно понятным, 
обеспечивать удобную навигацию, между разделами, содержать кнопку 
запуска таймера для учета времени выполнения задач и наглядные индикаторы статуса выполнения задач.

1.4.2.  Требования к функциям (задачам), выполняемым системой:

- Функции веб-приложения (Серверная часть):
1) Обработка запросов пользователей на создание, редактирование и удаление задач.
2) Фиксация временных затрат по каждой задаче.
3) Хранение и обработка данных о задачах, временных сессиях и пользователях в базе данных.
4) Формирование статистических отчетов и визуализация данных.
5) Обеспечение безопасности соединения (авторизация пользователей).
6) Предоставление API для взаимодействия с клиентской частью.

- Функции веб-интерфейса (Клиентская часть):
1) Отображение списка задач с возможностью фильтрации по статусу, категории и приоритету.
2) Запуск и остановка таймера для учета времени выполнения задач.
3) Создание, редактирование и удаление задач с указанием названия, описания, дедлайна и приоритета.
4) Отображение уведомлений о приближающихся дедлайнах.
 
1.4.3.     Требования к видам обеспечения:  

1.4.3.1. Требования к лигвистическому обеспечению системы:

Средством взаимодействия пользователя с системой, является русский язык.

1.4.3.2. Требования к входным и выходным данным:

- Входными данными являются название задачи, описание, дата дедлайна, 
приоритет, категория, время начала и окончания выполнения задачи.

- Выходными данными являются список задач с фильтрацией, отчеты по временным затратам,
- диаграммы распределения времени по категориям, уведомления о дедлайнах.
