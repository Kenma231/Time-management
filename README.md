Руденко А.Е. (ИУК5-52Б)

Название: Разработка системы учета времени, управления задачами и анализа продуктивности.

Назначение системы: Система предназначена для учета рабочего времени, планирования задач и анализа эффективности их выполнения.

Цель создания системы: Избавить пользователей от необходимости использования разных инструментов для планирования и учета времени, обеспечив единое пространство для управления задачами и временными затратами. Предоставить руководству инструмент для анализа эффективности использования рабочего времени сотрудниками.

Описание объекта автоматизации: Процесс учета рабочего времени и управления задачами включает в себя создание, распределение и отслеживание выполнения задач, фиксацию временных затрат по каждой задаче, формирование отчетных данных о продуктивности.

Этапы работы:
1. Оформление ТЗ. Описание требований к системе.
