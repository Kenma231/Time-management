1. Общие сведения
1.1 Наименование системы. 
MediaPulse - веб-приложение для планирования задач и ведения медиаплана для медиа студенческого совета.
1.2 Основание для разработки. 
Задание на курсовую работу по дисциплине «Модели данных».
1.3 Исполитель
Исполнитель: студент группы ИУК5-52Б Руденко А.Е.
Руководитель: Кириллов В.Ю

2. Назначение системы
2.1 Назначение системы
Система предназначена для участников медиа студенческого совета и позволяет вести общую доску задач, 
распределять задачи между участниками, формировать медаиплан публикаций. Система заменяет переписки единым рабочим
пространством.
2.2 Цель создания системы
Сократить время на согласование и постановку задач, обеспечить прозрачность статуса каждой публикации
и исключить потерю задач в чате.

3. Объект автоматизации и участники
3.1 Объект автоматизации
Деятельнось медиацентра студсовета по планированию, распределению и контролю задач,
а также по ведению медиаплана публикаций.
3.2 Участники процесса
Гость - не выполнивший вход, доступ к регистраии, входу и доске по ссылке просмотра.
Участник - зарегестрированный пользователь, состоящий в доске, берет задачи, закрывает их, учитывает время
выполнения.
Руководитель - зарегестрированный пользователь, с правом создавать задачи, вести медиаплан, управлять 
количеством участников, назначать задачи.
Администратор - сотрудник оператора платформы, управляет учетными записями, 
тестирует, не имеет доступа к содержимому задач.
3.3 Ключевые термины
Доска (группа) - группа участников с общей доской и общим медиапланном.
Задача - отдельное дело группы, название, описание, приоритет, срок, отвественный/е, статус.
Главный по задаче (отвественный) - участник группы, назначенный отвечать за выполненния задачи.
Публикация - задача особого типа, входящая в медиаплан: канал, дата выхода, время выхода, статус публикации.
Медиаплан - упорядоченный по даам список публикаци редакции на период (месяц).
Недельный список - предоставление задач, срок или дата публикации которых попадает в текущую неделю.
